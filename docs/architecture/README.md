# Enterprise BPM System - Architecture Documentation

## Overview

The Enterprise BPM System follows a **Clean Architecture** approach with microservices design. See full documentation in README.md for detailed architecture information.

## Quick Links
- Domain Layer: `/src/Core/BPM.Core.Domain`
- Workflow Engine: `/src/Core/BPM.Core.WorkflowEngine`
- Infrastructure: `/src/Infrastructure`
- Services: `/src/Services`

## Key Components
1. **Process Service**: Workflow execution and management
2. **Forms Service**: Dynamic form handling
3. **Identity Service**: Authentication and authorization
4. **Integration Service**: External system connectivity
5. **Analytics Service**: Reporting and insights
